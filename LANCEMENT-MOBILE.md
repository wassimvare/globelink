# Lancer GlobeLink sur téléphone

Il n'y a plus deux modes à choisir.

1. Décompresse entièrement le ZIP sur le PC Windows.
2. Garde au moins 4 Go libres pour le premier lancement.
3. Double-clique sur `LANCER_GLOBELINK.bat`.
4. Attends l'adresse HTTPS verte.
5. Scanne le QR code ou envoie l'adresse au téléphone.
6. Garde la fenêtre PowerShell ouverte.

Le mode HTTPS est utilisé automatiquement : connexion Google, micro et caméra
fonctionnent dans le même lancement. L'adresse temporaire change lorsque tu
fermes et relances le programme.
